x402 Suite · flagship · USDC on Base

Open-source Resy that AI agents can book.

A self-hosted restaurant reservation server with x402 micropayments: $0.001 to see real availability, a $0.01 refundable hold to claim the table. Confirmation, cancel token, refund terms, and a calendar invite come back in the same HTTP response.

Pricing

RoutePriceThe artifact you get back
GET /availability$0.001Open slots — date, time, seatable party sizes, table types, open-table counts
POST /book$0.01 (refundable)Confirmed reservation: table, refund terms, cancelToken, ledger entry, base64 .ics invite, HMAC signature
POST /cancel/:idfreeCancellation record + refund ledger entry (auth by cancelToken)
GET /info · /.well-known/x402freeProfile, hours, machine-readable payment manifest

How a paid call works

1 · Request

POST /book with no payment. Server replies 402 with exact payment requirements (amount, USDC contract, recipient).

→
2 · Pay

Client signs an EIP-3009 USDC authorization and retries with the X-PAYMENT header. Facilitator verifies & settles on Base.

→
3 · Artifact

200 with the reservation in the body and a settlement receipt in X-PAYMENT-RESPONSE. Done in seconds.

Quickstart — agent side

import { wrapFetchWithPayment } from "x402-fetch";
import { privateKeyToAccount } from "viem/accounts";

const payFetch = wrapFetchWithPayment(fetch, privateKeyToAccount(PRIVATE_KEY));

const avail = await payFetch("http://localhost:4021/availability?party=2").then(r => r.json());
const { date, time } = avail.slots[0];

const booking = await payFetch("http://localhost:4021/book", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({ date, time, party: 2, name: "Agent Ada" }),
}).then(r => r.json());

console.log(booking.reservationId, booking.cancelToken, booking.ics);
